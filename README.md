# 📚 Kirsh Manga Reader

[![GitHub release](https://img.shields.io/github/v/release/dmitrykirsh/kirsh-manga-reader?label=release)](https://github.com/dmitrykirsh/kirsh-manga-reader/releases/latest)

[![Stars](https://img.shields.io/github/stars/dmitrykirsh/kirsh-manga-reader?style=social)](https://github.com/dmitrykirsh/kirsh-manga-reader)

Легкий, быстрый и стильный нативный ридер манги для Windows. Предназначен для комфортного чтения локальных коллекций манги в форматах папок и архивов, с автоматическим отслеживанием прогресса, **встроенным загрузчиком манги с сайтов** и **страницей информации о манге с автоматическим подтягиванием данных с MangaDex**.

**Интерфейс полностью переписан на QML**: левая рейка, новая страница манги и читалка (см. раздел «Оформление» ниже). Загрузчики, MangaDex/MAL, формат конфига и кэша — прежние.

- Лента (вертикальный режим) стала быстрее и стабильнее: упрощена перестройка раскладки при скролле и масштабировании, меньше лишних пересчётов на каждый кадр

## ✨ Возможности

### 📥 Скачивание манги
- **Поддержка сайтов**: MangaLib, HentaiLib, SlashLIB/YaoiLib, Com-X.life, MangaHub.ru, MangaBuff.ru, а также сеть ReadManga/MintManga (SeiManga, Usagi, Zazaza и их зеркала)
- **Автоопределение сайта** по вставленной ссылке
- **Авторизация через браузер**: достаточно войти 1 раз, куки и токены сохраняются; один аккаунт MangaLib работает и для HentaiLib, и для SlashLIB
- **Импорт куки из файла** — для сайтов, которые блокируют автоматический вход через браузер (экспорт расширением вроде "Get cookies.txt LOCALLY")
- **Отмена в любой момент**: авторизацию и само скачивание можно прервать кнопкой «Отмена», не дожидаясь тайм-аута
- **Выбор формата**: папки с картинками или CBZ (архив)
- **Автоматическая упаковка в CBZ**: по томам — на всех поддерживаемых сайтах
- **Автообновление драйвера браузера**: не нужно вручную скачивать chromedriver/edgedriver
- **Chrome или Edge**: если Chrome не установлен, авторизация автоматически пойдёт через Edge

### 📂 Чтение манги
- **Поддержка форматов**: обычные папки с изображениями, архивы `.zip`, `.cbz`, `.rar`, `.cbr`
- **Полная автономность**: утилита `UnRAR.exe` уже встроена в установщик
- **Вертикальный режим (для манхвы/веб-тунов)**: непрерывная лента вместо страниц, переключается отдельно для каждой манги, с поддержкой зума (Ctrl+колесо) и виртуализацией (в памяти держатся только видимые страницы)
- **Кэш и предзагрузка страниц**: соседние страницы декодируются в фоне заранее — перелистывание мгновенное
- **Оглавление по всей серии**: быстрый переход к любой главе любого тома, не выходя из читалки (работает с CBZ, папками, RAR/CBR)
- **Отслеживание прогресса**: автоматическое сохранение последней прочитанной страницы
- **Экспорт/импорт прогресса**: перенос прогресса чтения между устройствами через настройки
- **Статус и оценка**: читаю / прочитано / в планах / брошено + оценка 1-5 звёзд, бейджем на карточке
- **Вкладки**: "Библиотека", "Продолжить чтение", "Завершено", "В планах"
- **Поиск по библиотеке**: поле в шапке, фокус — `Ctrl+F` или `/`

### 🎨 Интерфейс и управление
- **Контекстное меню**: статус, оценка, удалить прогресс, отметка о прочтении, переименование, смена обложки, удаление с устройства
- **Открыть в проводнике**: выделить файл/папку из контекстного меню
- **Пользовательские обложки**: установка из файла на ПК, по прямой ссылке или автоматически с MangaDex
- **Удобный ридер**: плавный зум, подгонка по высоте окна, интуитивное управление мышью и клавиатурой
- **Проверка обновлений**: приложение само подскажет, когда на GitHub выйдет новая версия

### 🎨 Оформление
Интерфейс написан на QML (Qt Quick); проверка по критериям доступности, типографики, цвета и движения — в [docs/design-audit.md](docs/design-audit.md).

- **4 темы**: Onyx & Amber, Catppuccin Mocha, Nordic Slate, Shonen Crimson. Каждая тема — полноценный набор токенов (фон, поверхности, границы, текст, акцент), а не перекраска одного акцентного цвета — контраст проверен для каждой (текст ≥ 4,5 : 1)
- **Левая рейка**: в покое — узкая, при наведении раскрывается и показывает подписи; полностью управляется с клавиатуры
- **Карточки**: обложка с тонкой обводкой, прогресс, статус на обложке; правая кнопка мыши или клавиша Menu — меню
- **Страница манги**: обложка, сведения и главное действие «Читать / Продолжить» сверху; ниже тома и главы с прогрессом каждого
- **Читалка**: панели появляются при движении мыши и уходят сами, не перекрывая страницу; щелчок по левой/правой трети листает; `M` — страницы/лента; оглавление по всей серии, переход по номеру страницы
- **Движение**: короткое (≤ 240 мс), без лишнего; учитывает системную настройку Windows «отключить анимации»

### 📖 Страница информации о манге
Клик по серии/тайтлу в библиотеке открывает отдельную страницу с информацией о манге — вместо того, чтобы сразу переходить в читалку.

- **Данные подтягиваются автоматически** с [MangaDex](https://mangadex.org) — это открытый, бесплатный и общедоступный API (без ключа и регистрации), которым пользуется само приложение через прямые HTTP-запросы. Поиск идёт по названию папки/файла на диске
- **Что показывается**: обложка, оригинальное и русское название (если есть), автор, художник, жанры, статус (продолжается/завершено/и т.д.), год выпуска, возрастной рейтинг (18+), описание (на русском, если MangaDex его предоставляет, иначе на английском), количество глав
- **Локальное кэширование**: один раз найденные данные сохраняются на диске — повторное открытие той же манги не обращается к сети заново
- **Тома и главы**: строится настоящее оглавление том → главы, поддерживаются все распространённые способы организации файлов на диске:
  - том = отдельный архив (`vol1.cbz`, `vol2.cbz`...)
  - том = папка, внутри которой лежат главы-архивы (`Том 01/Глава 001.cbr`, `Глава 002.cbr`...)
  - том = папка с одним архивом внутри (распознаётся прозрачно, как обычный том)
  - один архив содержит несколько глав внутри себя — тоже разворачивается в дереве
  - клик по главе открывает читалку сразу на нужной странице
- **Статус и оценка** — прямо на странице, двумя отдельными кнопками (читаю/прочитано/в планах/брошено и оценка 1-5 звёзд)
- **Кнопка «🔄 Обновить»** — принудительно запросить данные заново, если что-то изменилось или подтянулось неверно
- **Ручная привязка к MyAnimeList**: кнопка «🔗 Изменить ссылку» — если автопоиск на MangaDex ошибся или ничего не нашёл, можно вставить ссылку на страницу тайтла на MyAnimeList. Данные при этом всё равно берутся с MangaDex (сверка идёт по ID из ссылки среди результатов поиска) — сам MyAnimeList/сервис Jikan используется только как запасной источник, если сверка не дала результата
- **Кнопка «📖 К манге»** в читалке — вернуться со страницы чтения обратно на страницу информации, не выходя в библиотеку

## 📥 Установка

Отдельного установщика нет — программа распространяется в виде готового исполняемого файла.

1. Скачайте `KirshMangaReader.exe` со страницы [Releases](https://github.com/dmitrykirsh/kirsh-manga-reader/releases) репозитория
2. Запустите файл — установка не требуется, программа работает сразу
3. Откройте **Настройки** (⚙), укажите корневую папку с вашей коллекцией манги и нажмите "Сохранить изменения"

## 🛠️ Сборка из исходников

1. **Установите Python 3.10+**

2. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/dmitrykirsh/kirsh-manga-reader.git
   cd kirsh-manga-reader
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите программу**:
   ```bash
   python mr.py
   ```

   Точка входа `mr.py` — тонкая обёртка, вся логика приложения находится в пакете `app/`.

### 📦 Сборка EXE (опционально)

Если хотите собрать самостоятельный исполняемый файл, используйте готовый `KirshMangaReader.spec`:

```bash
py -m pip install pyinstaller
py -m PyInstaller KirshMangaReader.spec --noconfirm
```

Готовый EXE появится в папке `dist\KirshMangaReader.exe`

| Быстрый зум в точку | Двойной клик левой кнопкой мыши (ЛКМ) |
| Перейти к конкретной странице | Клик по тексту "X из Y" внизу окна |
| Оглавление | Кнопка "📑 Оглавление" вверху окна |
| Вертикальный режим (манхва/веб-туны) | Кнопка "📜 Вертикальный режим" вверху окна |

| Выход в библиотеку | `Esc` или Боковая кнопка мыши (Назад) |

## 🔑 Авторизация для скачивания

Для скачивания манги 18+ или манги с сайтов с ограниченным доступом нужна авторизация:

| Сайт | Что нужно |
| :--- | :--- |
| **MangaLib / HentaiLib / SlashLIB** | Токен (для манги 18+). Получается автоматически через браузер при нажатии "Получить токен" — один аккаунт работает для всех трёх сайтов |
| **Com-X.life** | Куки. Получаются автоматически через браузер при нажатии "Авторизоваться" |
| **ReadManga/MintManga и зеркала** | Куки. Выберите или введите домен для входа и нажмите "Авторизоваться", либо импортируйте куки из файла, если конкретное зеркало блокирует автоматический вход |
| **MangaHub.ru** | Куки, но не обязательны — большинство манги скачивается без входа. Нужны только для приватного/18+ контента; получаются автоматически через браузер при нажатии "Авторизоваться" |
| **MangaBuff.ru** | Куки, но не обязательны — главы скачиваются без входа. Нужны только для закрытых/18+ глав; получаются через браузер при нажатии "Войти в аккаунт" |

**Важно**: для авторизации требуется установленный браузер Google Chrome или Microsoft Edge (если Chrome не найден, приложение автоматически использует Edge).

Некоторые зеркала сети ReadManga/MintManga защищены анти-бот системами на уровне CDN и могут не поддаваться автоматическому скачиванию даже при успешной авторизации — это ограничение конкретного зеркала, а не самой программы. Если один домен не работает, попробуйте другое зеркало той же сети.

### Если сайт блокирует автоматический вход через браузер

Для сайтов с авторизацией через **куки** (Com-X.life, ReadManga/MintManga и зеркала) — если кнопка «Авторизоваться» не срабатывает, можно импортировать куки вручную:

1. Установите расширение браузера [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
2. Войдите в аккаунт на нужном сайте в своём обычном браузере (Chrome/Brave/Edge)
3. Откройте расширение прямо на странице сайта, выберите формат **JSON** и нажмите **Export**
4. В диалоге скачивания нажмите **«📁 Импортировать куки из файла»** и выберите сохранённый файл

Для MangaLib/HentaiLib/SlashLIB этот способ не нужен — там используется токен, а не куки (кнопка «Получить токен»).

## ⚙️ Хранение данных

- **Настройки программы, прогресс, метаданные (статус/оценка)**: `%LOCALAPPDATA%\KirshMangaReader\reader_config.json`
- **Токен MangaLib/HentaiLib/SlashLIB**: `%LOCALAPPDATA%\KirshMangaReader\mangalib_token.json`
- **Куки Com-X.life**: `%LOCALAPPDATA%\KirshMangaReader\comx_cookies.json`
- **Куки ReadManga/MintManga** (по одному файлу на домен): `%LOCALAPPDATA%\KirshMangaReader\group_cookies_<домен>.json`
- **Куки MangaHub.ru**: `%LOCALAPPDATA%\KirshMangaReader\mangahub_cookies.json`
- **Куки MangaBuff.ru**: `%LOCALAPPDATA%\KirshMangaReader\mangabuff_cookies.json`
- **Пользовательские обложки**: `%LOCALAPPDATA%\KirshMangaReader\custom_covers\`
- **Кэш информации о манге (MangaDex/MAL)**: `%LOCALAPPDATA%\KirshMangaReader\manga_info_cache\`
